## 1. 가정 (v1과 같음, 바뀐 곳만 굵게)

- 방치 입력: KHD 방치 Sim을 `idle_feed.py`가 import해 그대로 돌리고(읽기만), 접속별 처치·스테이지·처치 골드, 하루 골드·균사석·뽑기를 기록했다. 라이브 = 지금 표 + 공속 275(KHD `current`), v2 = KHD v2 + D1(배수 150, `day_v2b.json`)이다. 보통 하루 = 30분·4h·20분·5h·40분·15h, 광고 0.5.
- 세계수 공식은 `WorldTree*.cs` 그대로이고, 정책도 v1과 같다: 보따리 → 장식 받기·놓기 → 전투 → 부탁 → 선물 1번 → 공물 전부 → 나이테·진화 → ★ → 공방.
- 예산: 세계수 수입 + 방치 골드·균사석의 10%. 꼬마 뽑기 = 하루 뽑기의 25%.
- **되먹임 (`feedback.py`)**: 세계수 날짜별 효과(전날 끝 값)를 KHD Sim의 공격·체력·재생·치명 확률(Min 1)·치명 피해·처치 골드(전투 골드 → 앱 밖 골드도 따라감)·보스 균사석에 넣는다. 앞당김 = d − (기준선이 d일 스테이지에 처음 닿는 날).
- 되먹임에 **넣지 않은 것**: 세계수 재화 흐름(보따리·부탁 골드 수입, 나이테·진화·공방 골드 소모, 균사석 순소모). v2 1~45일에는 세계수 골드 순소모가 하루 골드의 3~8%(쓰기 > 수입)라, 넣으면 방치가 오히려 조금 늦어진다. 그래서 위 앞당김은 상한 쪽이다.
- **오차**: 챕터 보스(10스테이지마다) 때문에 v2 앞당김 판정은 ±1~2일 단위로 튄다. 검증 표의 "치명 피해 +0.1만 넣으면 −2일"(늦어짐)도 같은 잡음이다. 하루 = 25.5시간(KHD 일정).

## 8. 이슈 (사용자 결정)

1. **U1 (전투 효과 크기)**: 지금 기준(앞당김 ≤ 3일)이면 세계수 전투 효과는 공격·체력 +2%로 거의 장식 수준이다. 라이브는 공격 +1%만으로도 45일에 4일 앞당겨진다. "세계수가 전투를 키운다"를 살리려면 KHD 방치 곡선이 세계수 효과를 품게 하는 U1(b)가 필요하다. 그 경우 v1 쪽 값(공격·체력 +10~30%)으로 되돌릴 수 있다.
2. **라이브 45일 판정**: 라이브 표의 49일부터 폭주(보스 균사석 5+s/10 → 뽑기 → 장비 되먹임) 때문에 45일 앞당김은 0으로 만들 수 없다. 30일로 판정하는 데 관리자 동의가 필요하다.
3. U2(공속 제거)·U3(앱 밖 시간과 창고)·U4(D4)는 검증 7절 그대로다. 이번 수치는 지금 결정(공속 0, 창고 = 앱 켠 동안만, D4 없음)을 기준으로 했다.
